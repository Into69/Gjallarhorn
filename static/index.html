Probe scanner — passive WiFi client detection

Captures 802.11 probe-request frames on a monitor-mode wireless interface. With Auto-configure monitor mode on, Gjallarhorn runs the ip link/iw commands itself and restores the interface on stop — needs CAP_NET_ADMIN on the python binary or root. Otherwise put the interface in monitor mode beforehand: 

sudo ip link set wlan1 down
sudo iw dev wlan1 set type monitor
sudo ip link set wlan1 up
