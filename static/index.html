Bluetooth Low Energy (BLE)

Bluetooth Classic (BR/EDR)

Linux / BlueZ only. Most already-paired devices stay silent — Classic inquiry only finds devices in discoverable / pairing mode. Briefly stalls the BLE scanner while the controller switches transports.

Fixed interval: independent timer, fires every Scan interval seconds. After N BLE scans: the BLE loop signals this scan once every N completed BLE scans — the Scan interval stays as a safety-net fallback if BLE scans stop coming in.

GPS
Probe scanner — passive WiFi client detection

Captures 802.11 probe-request frames on a monitor-mode wireless interface. File caps don't propagate from python to subprocesses, so the scanner needs CAP_NET_ADMIN on the binaries it spawns: 

sudo setcap cap_net_admin,cap_net_raw+eip $(which iw)
sudo setcap cap_net_admin,cap_net_raw+eip $(which tshark)

setup.sh does this automatically. Live status (current channel, probe rate, last probe) is on the Map tab's sidebar card.

Location clustering

Effective radius = static threshold + (current speed × t). At rest the static threshold applies. At 10 m/s with t=60 s, the bubble is ~625 m and the sensor reaches its edge after ~1 minute. Capped at 5 km. Drawn geofences are user-authoritative — they're never merged away and keep their drawn radius.

What it does

            

              Gjallarhorn is a roaming sensor that catalogues every Wi-Fi
              and Bluetooth device nearby, clusters sightings into the
              locations you visit, and raises alerts when a device looks
              like it's following you between them.
            

            

              Gjallarhorn was the watchman's horn in Norse myth, blown by
              Heimdall to warn the gods of approaching threats. The intent
              here is the same — a quiet sentinel that watches the RF
              spectrum and sounds the alarm when the heuristics flag a
              follower.
            

          


          

            
Capabilities

            
    
              
  • Wi-Fi AP scan — active scan via the OS, BSSID / vendor / encryption.
    • 
              
  • BLE — bleak-driven advertising capture, split by public / random address.
    • 
              
  • Bluetooth Classic — optional BR/EDR inquiry through BlueZ, with Class-of-Device decoding.
    • 
              
  • Probe-request capture — passive Wi-Fi client detection via monitor-mode.
    • 
              
  • GPS clustering — gpsd fix stream resolves into location bubbles, auto or drawn.
    • 
              
  • Alerts — value, per-location, and follower-detection rule types with Discord delivery.
    • 
              
  • Reports — PDF export with maps, recurrence tables, suspect callouts.
